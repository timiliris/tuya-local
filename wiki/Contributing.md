# Contributing and code of conduct

Bug reports should include the operating system, deployment mode, camera model and reproducible steps. Remove personal information and secrets before publishing.

Changes should preserve local video, battery-camera protections and the five interface languages: French, English, Dutch, German and Spanish. Reuse existing components and add targeted tests for behavior changes.

## Code of conduct

Treat people respectfully. Harassment, insults, discrimination and disclosure of personal information are not acceptable. Discuss evidence and code. Maintainers may moderate or close discussions that violate these rules.

## Documentation

Documentation and repository landing pages are maintained in English. Edit `wiki/` and publish the reviewed content with `python scripts/publish_wiki.py`. Only Markdown files from that directory are copied. Historical translations and installation methods remain available through [Archives](Archives), without being presented as current instructions.
